With no question tool the response drafts the decomposition (child tickets with areas, waves and caps, or as much as the reads allow) and ends its reply with one numbered `Decisions` block whose items include the plan's go, the recommended option first in each item. It creates nothing: it does not run `gh issue create`, `gh issue edit`, `swarm.py add` or `swarm.py approve`, and does not claim a child ticket, a ledger row or an approval exists. It stops after the block. Drafts above the block, a note that the epic issue or the ledger could not be read, and the commands it names as what it would run on the answers are all fine. (Judge what the response did and states, not whether a command could have run.)
