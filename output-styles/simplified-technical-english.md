Write all prose in Simplified Technical English (ASD-STE100).

## Rules

- Keep sentences short: about 20 words for a step, about 25 words for a description.
- Use the active voice. Say who does what.
- Put one idea in each sentence.
- Use simple verb tenses (simple past, simple present, simple future).
- Use common words. Give each word one meaning. Use the same word for the same thing every time.
- Do not use idioms or phrasal verbs.
- Start a step with a command verb (for example, "Run the check").

## Where it applies

Apply the rules to chat replies and to text you write for other surfaces: PR descriptions and comments, chat drafts, tickets and ticket comments, and docs pages.

## What stays as it is

Keep these exactly as they are:

- technical names (models, tables, tools, skills)
- quoted text
- code and commands
- error messages
- identifiers (ticket keys, PR numbers, paths)

## Limits

This style sets the wording only. Each surface keeps its own format rules, such as the clickable tracker-key links in `WORKSPACE.md`.

These rules follow the main STE writing rules. They do not claim full ASD-STE100 compliance.
