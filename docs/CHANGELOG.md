# Kit changelog

Newest first. One line per behaviour change: `date · unit vN · what changed`. Typo/wording fixes
do not bump a version. The generated per-release log is the root [`CHANGELOG.md`](../CHANGELOG.md)
(conventional-release, [`contributing.md`](contributing.md) § Releases); this file stays the per-unit behaviour log. Dates are the
merge date in UTC, as GitHub shows it — a shared file cannot carry one machine's zone. A removed
skill or agent keeps its last version in git history: `git log --diff-filter=D -- skills/<name>` names the commit.

- 2026-09-27 · **env-init v7 · kb.py** — `kb.py discover` shell-quotes every value it fills into a `cli` plan's `run:` line and its `verify:`/`note:` (the name, `{config.…}` and `{row.…}` values and an unset placeholder, filled in one pass so a filled value is never re-scanned; a nested `{row.x.y.{name}}` selects the row by the raw name, then quotes its value) and prints the same command as an `argv:` JSON list; a key or name with a control character is refused, so a `NEEDS` line lifted from a PR, ticket or chat can no longer run code or forge a plan line; env-init runs the `run:` line (it said `call:`) (#131). Machines: nothing to do.
- 2026-09-27 · **kit-health v45 · leak_shapes.py · review_gate.py** — every leak-shape match on a line is checked against the allow-list (`leak_shapes.line_hits`: an allowed first value no longer hides a second one; a span two shapes both match is still one hit); an allow entry must cover the whole `<path>:` (`docs/a` no longer allows a hit in `docs/ab.md`); one skip rule, `leak_shapes.skip_path` (`fixtures/` dirs, binary suffixes, the scanners' own files), is used by kit-health and by the review gate in diff and `--tree` mode, so the two never disagree on which files they read (#164). Machines: nothing to do; a line with two values may now show two hits.
- 2026-09-27 · **session.py · gen_sessions.py · fsutil.py · context-db/Makefile** — a session name must be `[A-Za-z0-9][A-Za-z0-9._-]{0,63}` and resolve inside `sessions/` (`NAME=../INDEX` overwrote the store index); the `session-*` recipes pass `NAME`/`WORKING`/`RESP`/`NOTE`/`NEXT`/… to session.py as the variables' unexpanded values, single-quoted and `unexport`ed, so quotes, `$(…)`, backticks and `$(shell …)` in the text are data; a newline in a value cannot forge a frontmatter field; session docs, `SESSION_INDEX.md` and the archive index are written atomically (new `fsutil.atomic_write`), one registry lock serialises the session and its heartbeat, the ledger append is locked and happens after the doc write; `gen_sessions.py` reads front matter with the shared parser (a `---` rule in the body stays body) and names an unreadable file instead of crashing (#132). Machines: nothing to do.

- 2026-09-27 · **review_gate.py · ci.yml** — on a PR, CI runs the base branch's `review_gate.py` (and so its `leak_shapes.py`) against the head, and the gate reads `skills/kit-health/allow.txt` as the merge base has it: a PR can no longer add an allow line, relax a shape or edit the gate to pass its own leak; the diff is read NUL-separated (`--name-status -z`, `--numstat -z`), so a path git would quote, a rename or a copy is scanned under its real new path and a binary file is skipped explicitly (#129).
